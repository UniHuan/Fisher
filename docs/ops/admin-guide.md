# 运营后台操作手册

适用范围：`fish-admin.unihuan.com` 或 staging 后台。  
相关文档：[数据质量报告](../qa/data-quality.md)、[数据采集 SOP](data-collection-sop.md)、[安全策略](../../SECURITY.md)

## 1. 角色与权限

| 角色       | 查看钓点 | 编辑/新增 | 发布/下线 | 核实 | 导入 | POI  | 字典 | 审计   |
| ---------- | -------- | --------- | --------- | ---- | ---- | ---- | ---- | ------ |
| 超级管理员 | 是       | 是        | 是        | 是   | 是   | 是   | 是   | 全部   |
| 运营       | 是       | 是        | 是        | 是   | 是   | 是   | 否   | 仅自己 |
| 审核员     | 是       | 否        | 否        | 否   | 否   | 只读 | 否   | 否     |

审核员登录后只能查看钓点和周边场所，不能保存、发布、下线或核实。运营不能维护字典，也不能删除钓点。

## 2. 登录

1. 打开后台域名。
2. 输入用户名和密码。
3. 首次登录按提示绑定 TOTP。
4. 用验证器扫描二维码，输入 6 位验证码。
5. 保存恢复码，离线保存，不放在共享文档。

注意：

- 密码至少 12 位。
- 连续登录失败会触发限流或锁定。
- 后台 Cookie 是 host-only `__Host-` Cookie，换域名或换浏览器需要重新登录。
- 不要把后台账号借给他人，不要共用 TOTP。

## 3. 钓点列表

顶部筛选：

- 状态：草稿、已发布、已下线
- 区域
- 关键词：钓点名称

列表操作：

- 查看：打开只读详情
- 编辑：运营和超级管理员可用
- 发布：草稿或下线钓点可用
- 下线：已发布钓点可用
- 核实：记录最近一次核实时间
- 周边：维护周边 POI

审核员只看到查看和周边。

## 4. 新增与编辑钓点

### 4.1 基本信息

必填字段：

- 钓点名称
- 区域
- 坐标
- 地址
- 鱼种
- 收费状态
- 水域类型
- 场所类型
- 开放状态
- 核实时间
- 封面图

草稿只要求钓点名称，发布时会统一校验全部必填字段。

### 4.2 地图选点

1. 点击“地图选点”。
2. 在地图上点击目标位置，或搜索地址后选择结果。
3. 如需自动回填地址，保留“更新地址”勾选。
4. 点击“使用这个位置”。
5. 确认坐标在深圳范围内。

坐标使用 GCJ-02。深圳范围纬度约 22.3 至 22.9，经度约 113.7 至 114.7。超出范围会被 API 拒绝。

地图 Key 未配置时，弹窗会显示“未配置腾讯地图 JS Key”。此时联系管理员配置构建变量和域名白名单，不要手工猜坐标。

### 4.3 图片

- 最多 9 张。
- 单张不超过 10 MB。
- 支持 JPG、PNG、WebP。
- 服务端会旋转方向、清除 EXIF 并重新编码。
- 上传成功后要先保存钓点。
- 第一张或手动选择的图片作为封面。

常见错误：

- “文件过大”：压缩图片或降低分辨率。
- “图片格式不支持”：转为 JPG、PNG 或 WebP。
- 上传成功但列表无图：保存钓点并刷新。

### 4.4 发布前检查

- 坐标和导航坐标是否准确
- 地址是否可导航
- 鱼种、收费、水域、场所是否正确
- 开放状态是否为开放、暂停或禁钓
- 禁钓点是否填写禁钓说明
- 封面图和详情图是否清晰
- 核实时间是否为最近一次实地或可靠来源核实
- 周边 POI 是否至少 3 个

## 5. 核实、发布与下线

### 标记核实

点击“核实”，确认后记录当前时间。核实时间会用于数据质量报告。

### 发布

发布前 API 会校验必填字段。失败时会显示字段级错误，按提示补齐后重试。

发布成功后：

- 小程序公开列表可见
- 详情页可访问
- 禁钓点仍默认不出现在列表
- 图片通过公开 URL 展示

### 下线

下线后小程序不再展示该钓点，历史数据保留。重新发布需要再次通过发布校验。

### 删除

只有超级管理员可以删除。删除前确认没有引用、没有审计或合规保留要求。

## 6. Excel 导入

1. 点击“Excel 导入”。
2. 下载模板。
3. 按模板填写钓点。
4. 上传文件并开始导入。
5. 查看成功数、失败数和错误 CSV。
6. 成功行会创建为草稿，失败行不会创建。
7. 同一文件重复上传会复用同一任务，不重复创建钓点。

导入规则：

- 一次最多 100 行。
- 文件不超过 2 MB。
- 坐标、字典值、必填字段按模板校验。
- 错误 CSV 保留行号和失败原因。
- 导入后仍需人工核实和发布。

## 7. 周边 POI

1. 在列表点击“周边”。
2. 查看已绑定 POI。
3. 新增 POI 时填写名称、类型、坐标和距离。
4. 保存后检查详情页展示。
5. 自动同步失败时，手工新增仍然可用。

POI 类型、距离和隐藏状态按运营规范维护。禁钓点不展示导航。

## 8. 字典维护

只有超级管理员可以打开“字典”。

- 区域
- 鱼种
- 水域类型
- 场所类型
- POI 类型
- 钓法
- 收费状态和单位

修改字典前确认没有线上钓点依赖旧值。停用优先于删除。

## 9. 审计日志

- 超级管理员可查看全部审计。
- 运营只能查看自己的审计。
- 审计记录包含操作人、动作、实体、时间、IP 和请求 ID。
- 敏感字段已脱敏，不记录令牌和密码。

发现异常操作时：

1. 记录时间、操作人和实体 ID。
2. 导出相关审计。
3. 通知安全负责人。
4. 必要时禁用账号并轮换会话。

## 10. 常见问题

| 现象               | 处理                                 |
| ------------------ | ------------------------------------ |
| 登录后立即退出     | 检查 Cookie、域名、HTTPS 和系统时间  |
| TOTP 验证失败      | 检查手机时间同步，必要时使用恢复码   |
| 发布提示字段缺失   | 按字段级错误补齐，草稿不会自动发布   |
| 地图空白           | 检查腾讯地图 Key、域名白名单和网络   |
| 图片上传失败       | 检查大小、格式、存储驱动和 OSS 权限  |
| 导入部分失败       | 下载错误 CSV，修正后重新上传         |
| 列表搜不到钓点     | 检查状态筛选、区域和关键词           |
| 小程序看不到新钓点 | 确认已发布、未下线、未被禁钓规则隐藏 |

## 11. 安全要求

- 不截图或分享包含 Token、Cookie、手机号或密钥的页面。
- 不使用共享账号。
- 离岗或角色变更时立即禁用账号。
- 发现异常登录、批量修改或数据泄露时按安全事件流程上报。
- 后台只通过 HTTPS 和公司网络或白名单访问。

## 12. 商品管理（UniHuan 商品扩展）

商品入口只有具备 `product:read` 权限的角色可见。超级管理员和运营可以查看、创建、编辑、归档商品并维护展示位置；审核员没有商品权限。商品管理使用独立抽屉，不进入钓点编辑器。

### 12.1 商品列表与编辑

- 筛选：状态（草稿、已上架、已归档）、分类、关键词。
- 列表列：封面、标题、分类、状态、渠道数、展示位置数、更新时间。
- 操作：编辑、归档。
- 分类：竿、轮、线、饵、帽子、防晒、配件、其他。
- 基本信息：标题必填，最多 80 字；副标题最多 120 字；描述最多 2000 字；排序权重越大越靠前。
- 保存草稿不要求图片和渠道；发布要求至少 1 张商品图、至少 1 个启用渠道，购买动作参数必须通过校验。
- 发布失败时按字段级错误补齐，商品保持草稿。归档商品不再出现在公开列表，公开图保留。

### 12.2 渠道与购买动作

- 第一版只支持微店（`weidian`）。后台不提供京东字段；服务端也只接受微店，提交其他渠道会返回校验错误。
- 每个商品只允许一个渠道。
- 购买动作类型：
  - 跳转微店小程序（`mini_program`）：需要 `app_id`（`wx` 加 16 位小写十六进制）和以 `/` 开头的 `path`，可选 `fallback_url`（`https://`）。
  - 打开 H5 链接（`h5`）：需要 `https://` 开头的 `url`。
  - 复制链接（`copy_link`）：需要 `https://` 开头的 `url`，可配置复制成功提示。
- 二维码 `qr` 预留给线下物料，第一版不开放。
- 参考价是展示文本，例如 `¥299 起`，不参与交易和结算。
- 停用渠道后商品卡不再展示该渠道；没有启用渠道的商品不会出现在公开列表。

### 12.3 商品图片

- 支持 JPG、PNG、WebP，单张不超过 10 MB。
- 服务端自动旋转、清除 EXIF、最长边缩到 1600 px 并转为 WebP，目标约 250 KB。
- 每个商品最多 9 张图，第一张或手动选择的图作为封面。
- 草稿图只写私有工作桶，通过 15 分钟签名 URL 预览，不要直接对外分享预览链接。
- 发布时复制到公开发布桶。发布前确认图片清晰、无联系方式和二维码。
- 归档商品保留公开图，不删除对象。

### 12.4 展示位置

- 第一版页面类型只开放钓点详情（`spot_detail`）。首页和情报详情（`home`、`report_detail`）是预留值，后台不开放。
- 品牌页是完整商品目录，不需要展示位置。
- 钓点定向（`scope=spot`）：选择一个已存在的钓点，鱼种必须为空。
- 鱼种定向（`scope=fish`）：选择一个或多个鱼种字典 key，最多 5 个，不填钓点。
- 排序：钓点定向优先于鱼种定向；同类型按排序值升序，再按商品排序权重降序。
- 起止时间可为空；当前时间不在窗口内的展示位置不生效。
- 停用的展示位置不生效。钓点下线后，该钓点的展示位置自动不生效，不需要删除。
- 保存时校验钓点存在、鱼种 key 来自字典；校验失败按提示修正。
- 删除展示位置只影响该位置，不删除商品。

### 12.5 商品审计

商品相关操作为 `product.create`、`product.update`、`product.archive`、`product.image_upload`、`product.placement_create`、`product.placement_update`、`product.placement_delete`。审计只记录商品 ID、状态、渠道、展示位置和目标 ID，不记录完整文案。
