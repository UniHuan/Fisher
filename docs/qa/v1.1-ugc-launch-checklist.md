# V1.1 公开 UGC 上线检查清单

- 日期：2026-11-20
- 用途：V1.1 体验成熟后，公开版本上线前的微信、法务、审核和运营检查
- 原则：体验版可以先进，公开版必须逐项确认

## 1. 微信类目与备案

- [ ] 查看当前小程序服务类目：公众平台 → 设置 → 基本设置 → 服务类目。
- [ ] 确认公开评论、鱼获、情报是否属于当前类目。
- [ ] 如不属于，评估增加“社交-社区/论坛”或其他合适类目。
- [ ] 准备类目所需资质、说明和截图。
- [ ] 确认小程序备案信息与主体一致。
- [ ] 确认名称“深圳钓鱼助手”已通过审核。
- [ ] 确认图标、简介、截图与实际功能一致。
- [ ] 保留微信审核沟通记录。

## 2. 法务页面

- [ ] 隐私政策上线：`https://fish.unihuan.com/legal/privacy`。
- [ ] 用户协议上线：`https://fish.unihuan.com/legal/terms`。
- [ ] 社区规范上线：`https://fish.unihuan.com/legal/community`。
- [ ] `UGC_TERMS_VERSION` 与页面版本一致。
- [ ] 小程序业务域名已加入 `fish.unihuan.com`。
- [ ] 微信隐私保护指引已更新并审核通过。
- [ ] 页面包含公司主体、联系方式、生效日期。
- [ ] 法务确认 UGC 授权、免责、违规处理和未成年人条款。

## 3. 内容安全

- [ ] `WECHAT_MINI_APPID`、`WECHAT_MINI_SECRET` 已配置。
- [ ] `WECHAT_MSG_TOKEN` 已在微信消息推送和服务器环境一致。
- [ ] `WECHAT_MSG_AES_KEY` 已在微信消息推送和服务器环境一致。
- [ ] 消息推送 URL 为 `https://fish-api-staging.unihuan.com/api/v1/wechat/media-check/callback`（生产替换域名）。
- [ ] 消息推送使用安全模式，`WECHAT_MSG_AES_KEY` 与微信 EncodingAESKey 一致。
- [ ] 文本 `msgSecCheck` 实测 pass/review/risky。
- [ ] 图片 `mediaCheckAsync` 实测回调。
- [ ] 回调签名、时间戳、去重和超时进入人工队列。
- [ ] 内容安全失败时功能开关能关闭。

## 4. 审核与运营

- [ ] 审核员账号和 `report:read`/`report:moderate` 权限。
- [ ] 运营和超级管理员的 `user:restrict`/`user:ban` 权限。
- [ ] 审核队列、举报队列、超时提醒可用。
- [ ] 24 小时处理承诺有人负责。
- [ ] 违规处理规则：驳回、限制、封禁。
- [ ] 用户申诉和客服渠道。
- [ ] 审核日志保留至少 1 年。

## 5. 数据与图片

- [ ] 公开图片路由可用，或 CDN 已配置。
- [ ] 私有桶不开公共读。
- [ ] 图片重编码、去 EXIF、大小和类型限制。
- [ ] 图片删除和下架后 404。
- [ ] 内容删除 24 小时内清理正文和图片引用。
- [ ] 备份和恢复演练。

## 6. 生产与灰度

- [ ] 生产 `features.ugc` 默认关闭。
- [ ] 灰度名单和开关操作人。
- [ ] 监控：发布量、审核量、举报量、错误率、时延。
- [ ] 回滚：关闭开关，公开列表和图片路由 404。
- [ ] 2 个 API 实例的共享限流和定时任务锁。
- [ ] 生产数据只走后台审核流程，不直接改库。

## 7. 上线判断

全部满足后再打开生产开关。任何一项不满足，保持体验版，不公开。
