# 微信小程序用户隐私保护指引填写草案

- 对应版本：2026-11-23
- 说明：以下内容用于微信公众平台“用户隐私保护指引”填写参考，提交前请法务确认

## 1. 开发者处理的信息

| 信息类型 | 用途 | 是否必须 |
| --- | --- | --- |
| 微信 openid、unionid | 登录、识别账号、内容归属 | 是 |
| 用户发布的内容（文字、图片、鱼种、重量） | 展示钓友情报、审核、钓点信息完善 | 是 |
| 相册中选择的图片 | 用户发布评论、鱼获、情报和反馈时选择图片 | 否，仅用户主动选择时读取 |
| 摄像头 | 用户拍照上传图片时使用 | 否，仅用户主动拍照时使用 |
| 昵称、头像 | 后续版本用户主动设置后展示 | 否 |
| 位置信息 | 按距离展示附近钓点、地图定位 | 否，可拒绝 |
| 设备信息、日志、截断 IP | 安全、排错、统计 | 是 |
| 点赞、举报、删除记录 | 互动、审核、违规处理 | 是 |
| 反馈联系方式（微信号或手机号） | 回访和问题处理，不公开展示 | 否，选填 |

## 2. 信息的使用

- 提供钓点查询、地图、详情、周边配套和钓友情报。
- 内容审核、举报处理、违规限制和账号封禁。
- 安全防护、故障排查、刷量识别。
- 匿名统计和产品改进。

## 3. 信息的共享

- 微信内容安全接口：文本和图片审核。
- 腾讯位置服务：周边 POI 查询。
- 阿里云 OSS、RDS：存储和数据库。
- 法律法规要求或司法机关依法要求。

## 4. 存储与保护

- 数据存储在中国境内。
- HTTPS 传输，私有桶不开公共读。
- 后台权限和审计日志。
- 按最小必要原则收集。
- 体验反馈及其中填写的联系方式保留 90 天，到期自动删除；审核日志保留至少 1 年。
